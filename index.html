Como usar

1. Qual forma de conexão escolher?

  • Driver do Windows/Mac: mais simples e funciona com qualquer impressora instalada no computador (Elgin, Argox, Zebra, Tanca…). Cadastre no driver um papel de 40 × 40 mm.
  • USB direto: o navegador envia comandos ZPL/TSPL/EPL direto para a impressora, sem janela de impressão. No Windows, se aparecer “Access denied”, é porque o driver do fabricante está usando a porta USB. Nesse caso, prefira o modo Driver.
  • Serial / COM: para impressoras ligadas por cabo serial ou adaptador USB-serial.
  • Impressora em rede (IP): o navegador não acessa a porta 9100 diretamente. Instale a impressora no Windows (porta TCP/IP) e use o modo Driver.

2. Alinhar na etiqueta pré-impressa

  1. Clique em Calibrar sensor (modos USB/Serial) ou use a calibração do próprio driver.
  2. Imprima uma etiqueta de teste e veja se os dados caíram em cima das linhas.
  3. Se tudo estiver deslocado, ajuste Deslocar → e Deslocar ↓. Se só um campo estiver fora, ajuste-o em Ajustar posições.
  4. A grade de alinhamento imprime linhas a cada 5 mm, que ajudam a medir as posições.

3. Tipo de papel

Risque a etiqueta com a unha. Se escurecer, é papel térmico e não precisa de fita. Se não escurecer, use impressora de transferência térmica com ribbon de cera.

4. Imprimir sem a janela do navegador (modo Driver)

Crie um atalho do Chrome com --kiosk-printing no final do destino. A impressão vai direto para a impressora padrão.

5. Publicar no GitHub Pages

  1. Crie um repositório e envie este arquivo com o nome index.html.
  2. Em Settings → Pages, escolha a branch main e a pasta / (root).
  3. Acesse pelo endereço https://SEU-USUARIO.github.io/NOME-DO-REPO/. O HTTPS é necessário para USB e Serial.

Os dados ficam salvos só no navegador de cada computador. Use Exportar/Importar em “Cadastros” para copiar entre máquinas.

Atenção: os prazos de validade de cada insumo devem seguir o manual da sua operação e a orientação sanitária. O sistema só calcula a data a partir do prazo que você informar.
